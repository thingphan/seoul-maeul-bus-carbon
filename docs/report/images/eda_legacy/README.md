## 🔎 운행 검증 그림

운행별 피크 예측과 차량 배치의 개별 그림은 [upgrade 폴더](../upgrade/)에 있고, 설명은 [운행 검증 상세](../../maeul_bus_upgrade_validation.md)에 있다.

- [운행 피크 분포와 사례](../upgrade/01_average_vs_trip_peak.png): 평균 수요로 판단한 후보에서 운행별 피크가 얼마나 달라지는지 보여준다. 기본 분석의 시간대 기준(18,951개 운행)으로 그려 보고서의 19,126개 기준과 초과율이 조금 다르다.
- [AI 검증 비교](../upgrade/02_ai_validation.png): 예측 포함률과 전환 후보 비중·정원 초과 위험의 절충을 보여준다. 그림의 ‘상한 초과’는 선택 운행의 카드 기반 피크 상한이 정원 16명을 초과한 비율을 뜻한다.
- [운영 제약과 차량 확보 규모](../upgrade/03_constraints_and_fleet.png): 제약에 따른 전환 범위 축소와 확보 차량 상한별 감축 효과를 보여준다.
- [TreeSHAP 설명](../upgrade/04_model_explanation.png): 정규화된 피크 예측에 대한 변수별 평균 절대 기여를 보여준다. 인과적 영향이나 승객 수 단위의 효과는 아니다.

보고서 그림 1~4는 [integrated 폴더](../integrated/)에 있다.
