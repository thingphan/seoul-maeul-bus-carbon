# 기존 EDA 및 보조 시각화

이 폴더는 기존 분석·보고서 작성 과정에서 만든 그림의 보관본이다. 현재 통합 보고서의 재계산 결과와 시나리오·분류·표본이 다를 수 있으므로, 제출본에 사용할 때는 최신 결과로 수치와 문구를 갱신해야 한다. 그림의 수치를 현재 분석 결과로 인용하지 않는다.

## 추가 AI·최적화 그림

다음 그림은 같은 저장소의 [upgrade 폴더](../upgrade/)에 있다. 통합 보고서에 없는 개별 그림도 이곳에서 확인할 수 있다.

- [운행 피크 분포와 사례](../upgrade/01_average_vs_trip_peak.png): 평균 수요로 판단한 후보에서 운행별 피크가 얼마나 달라지는지 보여준다. 통합 보고서와 표본 기준이 달라 초과율도 다르다.
- [AI 검증 비교](../upgrade/02_ai_validation.png): 예측 포함률과 전환 후보 비중·정원 초과 위험의 절충을 보여준다. 그림의 ‘상한 초과’는 선택 운행의 카드 기반 피크 상한이 정원 16명을 초과한 비율을 뜻한다.
- [운영 제약과 차량 확보 규모](../upgrade/03_constraints_and_fleet.png): 제약에 따른 전환 범위 축소와 확보 차량 상한별 감축 효과를 보여준다.
- [TreeSHAP 설명](../upgrade/04_model_explanation.png): 정규화된 피크 예측에 대한 변수별 평균 절대 기여를 보여준다. 인과적 영향이나 승객 수 단위의 효과는 아니다.

현재 통합 보고서에서 사용하는 그림은 [integrated 폴더](../integrated/)에 있다.
