## 3. 피크 예측 모형 비교(최종 검증 128,202개 운행)

![AI 검증 비교](images/upgrade/02_ai_validation.png)

| 방법 | 예측 상한 포함률 | 16명 이하 예측 비중 | 후보 운행의 정원 초과율 | 초과 / 후보 |
| --- | ---: | ---: | ---: | ---: |
| 과거 경험 Q99(학습 기간 노선·요일·시간대) | 87.92% | 24.24% | 5.34% | 1,658 / 31,075 |
| XGBoost Q99(목표 정규화) | 99.26% | 5.22% | 0.22% | 15 / 6,689 |
| XGBoost Q99(정규화 + 보정) | 99.29% | 5.11% | 0.21% | 14 / 6,553 |
| 직전 7일 변수를 뺀 XGBoost | 99.30% | 5.67% | 0.25% | 18 / 7,266 |
| 정규화 전 XGBoost Q99 | 99.52% | 0.00% | – | 0 / 0 |

- 정규화하지 않은 모형은 포함률이 가장 높지만 16명 이하로 예측한 운행이 하나도 없어 전환 판단에 쓸 수 없다.
- 직전 7일 변수를 빼도 목표 정규화에는 과거 수요 평균이 쓰이므로, 수요 이력이 전혀 없는 모형은 아니다.

![TreeSHAP 변수 기여](images/upgrade/04_model_explanation.png)

정규화 목표에 대한 Q99 모형의 평균 절대 기여는 직전 7일 피크 평균(0.097), 노선(0.087), 요일(0.035), 시각(0.019) 순이었다. 예측 기여를 설명하는 값이며 인과 효과가 아니다.
